# Python - More Data Structures

This directory contains Python exercises I completed while learning more about data structures and working with different types of data.

## Files

- 0-square_matrix_simple.py: Creates a new matrix with each value squared.
- 1-search_replace.py: Replaces a specific value in a list.
- 2-uniq_add.py: Adds the unique integers in a list.
- 3-common_elements.py: Finds elements shared by two sets.
- 4-only_diff_elements.py: Finds elements that appear in only one of two sets.
- 5-number_keys.py: Counts the keys in a dictionary.
- 6-print_sorted_dictionary.py: Prints dictionary keys in alphabetical order.
- 7-update_dictionary.py: Adds or updates a dictionary entry.
- 8-simple_delete.py: Removes a key from a dictionary.
- 9-multiply_by_2.py: Multiplies dictionary values by two.
- 10-best_score.py: Finds the key with the highest value.
- 11-multiply_list_map.py: Uses map() to multiply list elements.
- 12-roman_to_int.py: Converts Roman numerals into integers.

## What I Learned

Through these exercises, I practiced using lists, sets, dictionaries, functions, loops, and built-in Python tools to solve different problems.

## Running the Files

The exercises use Python 3. Run a file from the terminal using:

python3 filename.py
